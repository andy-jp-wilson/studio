# Phase 3: look at the band and panel

Start a **new** session in `~/code/projects/studio/playground/onboarding`, once in the terminal (`cd` there, then `claude`) and once in the Desktop Code tab. A session that was already open won't have the band or panel.

| # | Do this | You should see |
|---|---|---|
| 1 | Just start the session | **The band** above the prompt: `✓ Explore ─ ● Refine ─ ○ Build   Now  Ready when you are   1: Show  2: Save` |
| 2 | Look beside the conversation (Desktop) or to the side (wide terminal) | **The Studio panel**: Journey tab with your three stages, Happening now, Actions, and the footer with the working-memory bar. In a narrower terminal, type `/panel` |
| 3 | Ask "Make the help text a little quieter" | The band's **Now** changes as Claude works ("Reading styles.css", "Editing styles.css"), a **3: Stop** button appears, and the working line uses the same words |
| 4 | Watch the panel during step 3 | Happening now lists the steps with ✓ and ●, and **Did you know?** appears |
| 5 | Type `2` alone in the empty prompt and wait | It presses **Save** (a save point is made) |
| 6 | In the panel, press **Glossary**, then type "branch" in the search box | Only the matching word stays |
| 7 | In the panel, press **Build** under the stages | The band and panel both move to Build and say "You chose this stage". **Let Studio guess** undoes it |
| 8 | Press **Preview** (or **Open preview** if it's already running) | Your private preview starts or opens |
| 9 | Press **Send to Figma** | Claude asks which Figma file to use, and doesn't write anything until you say yes |
| 10 | Overall | Calm, readable, nothing cut off, colours sensible in light and dark |

Note anything that looks different between the terminal and Desktop, and send screenshots if you can.
